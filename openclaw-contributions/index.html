Scope and provenance policy
  • Sessions qualify through the exact OpenClaw group or explicit title markers; previews are never used for classification.
  • GitHub repositories use an explicit allowlist: openclaw/openclaw, jjjhenriksen/openclaw, openclaw/rfcs, openclaw-pet, clickclack, lossless-claw, and noderooms-openclaw-plugin variants.
  • Open PRs use the reference query is:pr is:open author:jjjhenriksen; recent public events are shown separately and are not treated as historical coverage.
  • Private GitHub activity is not shown; this export has no live API or session connection. A successful request is not proof of a complete historical universe; source limits and errors stay visible.

Refresh time is local to this browser. “Scope receipts” means the row has an explicit inclusion basis, not that the work has a merged code or release proof.
