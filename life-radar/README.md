# Life Radar Dashboard

A privacy-bounded public edition of Jacqueline Henriksen's Life Radar dashboard pattern.

Life Radar is a signal-first orientation surface for deadlines, capacity, calendar visibility, coursework, and cross-board priorities. The live OpenClaw board uses private connected sources; this repository intentionally contains only representative labels and static example values.

## Public boundary

- No personal calendar events, assignments, reminders, health data, session identifiers, or private workspace content are included.
- The live board remains the source for current personal planning.
- The public HTML demonstrates the visual hierarchy and interaction model, not live personal state.
